# Kivi — концепт-арт, черновик v1

Дата: 09.11.2026.
Статус: **черновик для утверждения**, не финальная модель.

## Как сделано

- Локальный SD WebUI (`D:\stable-diffusion-webui`), модель **Counterfeit V2.5 fp16**.
- 512×768 для full-body, 512×512 для портрета, 768×512 для листа.
- Euler a, 28–32 шага, CFG 7.0–7.5.
- Метаданные каждого изображения — в одноимённом `.json`.
- Облачная генерация была недоступна (недостаточно средств), поэтому использован
  локальный fallback.

## Файлы

| Файл | Что показывает | Статус |
|---|---|---|
| `kivi_fullbody_summer.png` | светло-мятный сарафан, сандалии, летний образ | лучший вариант одежды; **кардигана нет** |
| `kivi_fullbody_cardigan.png` | сарафан + белый кардиган | кардиган **длинный**, нужно укоротить |
| `kivi_portrait.png` | лицо, бирюзовые волосы и глаза, мягкая мимика | лучший портрет; одежда условная |
| `kivi_turnaround.png` | компоновка листа front/side/back + портрет | хорошая композиция; костюм фэнтезийный, не финальный |

## Что совпадает с ТЗ

- 18 лет, стройная, рост читается как 156 см.
- Длинные бирюзовые волосы, бирюзовые глаза.
- Реалистичный аниме, мягкие тени, без чиби.
- Светло-мятная гамма, летний сарафан, сандалии.
- Нет очков, наушников, украшений.

## Что требует правки

1. **Короткий кардиган.** Генератор плохо понимает «cropped cardigan»: либо не рисует его,
   либо делает длинным. В VRoid/Blender добавим отдельный слой — короткий кардиган
   до талии, открытый, поверх сарафана.
2. **Лист turnaround.** Костюм на листе отличается от выбранного; использовать его
   как референс композиции и пропорций, а одежду взять из `kivi_fullbody_summer.png`.
3. **Аксессуары.** На некоторых черновиках появлялись ленты/броши; в финале их быть не должно.
4. **Пропорции.** Для VRM нужен рост 156 см и нейтральная A-поза; сейчас позы
   художественные, не технические.

## Решение для 3D

- Базой для VRM берём `kivi_fullbody_summer.png`.
- Кардиган моделируем отдельно по `kivi_fullbody_cardigan.png`, но укорачиваем до талии.
- Лицо и причёску — по `kivi_portrait.png`.
- Компоновку листа — по `kivi_turnaround.png`.

## Лицензия

Counterfeit V2.5 распространяется по CreativeML OpenRAIL-M. Перед коммерческим
использованием проверить условия; для личного проекта ограничений меньше.
Изображения сгенерированы ИИ и не являются фотографиями реального человека.
