## 7. Известные ограничения

- **4 ядра / 8 потоков**: два тяжёлых CPU-процесса (STT + TTS + SDXL) одновременно
  дадут очередь; LLM и так на GPU.
- 16 ГБ VRAM — не бесконечность: 14B @8k (14,3 ГБ), Coder-14B @16k (15,3 ГБ)
  могут вытеснить аватар/браузер; gateway обязан считать свободную VRAM.
- Диск D: 100,5 ГБ свободно. 14B + SDXL + whisper + Qwen3-TTS помещаются, датасеты
  и видео — нет; при росте моделей нужен ещё SSD.
- WSL2/Docker отсутствуют: `code.run` остаётся Python-песочницей best-effort.
- 3D-аватар добавит 100–300 МБ VRAM; VRM-ассета и wake-модели всё ещё нет.
- 14B Q4 не установлена и не измерена; расчёт «~9–11 ГБ» — оценка, не факт.

### 8.1. Что уже установлено и что осталось

Установлено 12.11.2026:

- `Qwen3-14B Q4_K_M` — 9,0 ГБ, 14,6 tok/s @8192, 14 295 МБ;
- `Qwen2.5-Coder-14B Q4_K_M` — 9,0 ГБ, 21,6 tok/s @8192, 13 919 МБ;

- `faster-whisper-large-v3-turbo` — 1,54 ГБ, CPU int8, 11,7 с речи;
- SDXL base 1.0 — 6,46 ГБ, чекпойнт.

Осталось:

1. **SDXL runtime** — ComfyUI/SD WebUI, 1024×1024, 20 steps; `diffusers.from_single_file`
   на этой машине конфликтует с HF-кэшем конфига.
2. **Whisper + 8B Q4 + 3D-аватар** одновременно — проверить ~12,0 ГБ и shared memory.
3. **Qwen3-VL** — реальные скриншоты/PDF-страницы, замер latency.
4. **14B vs 8B Q4** — сравнить русский/код и выбрать дефолт по задаче.

### 8.2. Диск

- D: 100,5 ГБ — старые модели удалены, новые 14B/VL/Whisper/SDXL/Qwen3-TTS помещаются.
- Датасеты, видео и старые чекпойнты — только после освобождения места или
  установки дополнительного SSD.
- Модели держать на D:, не на C: (там 75,7 ГБ).

### 8.3. Конфиг

- `vram_total_mb` = **16384**, `safety_margin_mb` = **512**.
- `config/models.yaml` после чистки: 4B@8k = 7,8 ГБ, 8B Q4@8k = 9,5 ГБ,
  coder 7B@16k = 9,0 ГБ, Coder-14B = 15,4 ГБ, Qwen3-14B = 14,3 ГБ.
- Старые `deepseek`, `llama3`, `qwen2.5`, `Qwen3-8B Q5` удалены; default chat —
  8B Q4, default code — 7B coder.
- 14B добавлен в registry после замера: Qwen3-14B Q4 14 300 МБ,
  Coder-14B 15 400 МБ; оба — только по одному.

**Важно:** 16 ГБ не означают «всё сразу». Одна тяжёлая модель за раз —
по-прежнему правило; 16 ГБ позволяют держать рядом только лёгкие ASR/аватар.
