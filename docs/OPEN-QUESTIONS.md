## 2. Голос

**Решено:** Silero `baya`, локально.

| Версия | Файл | Статус |
|---|---|---|
| Silero `v4_ru` `baya` | `assets/voice-samples/silero_baya.wav` | базовая |
| Silero `v5_ru` `baya`, 48 кГц | `assets/voice-samples/silero_v5_baya_48k.wav` | чище, больше деталей |
| Silero `v5_ru` `baya`, очищенный | `assets/voice-samples/silero_v5_baya_48k_clean.wav` | high-pass, нормализация |
| Silero `v5_ru` `baya`, SSML | `assets/voice-samples/silero_v5_baya_48k_ssml.wav` | паузы, rate 95%, pitch −2% |
| Silero `v5_ru` `baya`, SSML + очистка | `assets/voice-samples/silero_v5_baya_48k_ssml_clean.wav` | SSML + постобработка |
| Silero `v5_ru` `baya`, 24 кГц | `assets/voice-samples/silero_v5_baya_24k.wav` | для совместимости |

Осталось:

1. Прослушать `v4` / `v5 48k` / `v5 clean` и выбрать финальный вариант.
2. Нужны ли записи жены (20–60 минут) и подписанное согласие?
3. Zero-shot (быстро) или fine-tuning (точнее, дольше)?
4. Допустим ли Edge TTS как fallback, если текст уходит в Microsoft? (по умолчанию — нет)

План клонирования: `docs/VOICE-CLONING.md`.
