## 1. Что уже решено

| Тема | Решение |
|---|---|
| Облако | Автоматически, локальные модели в приоритете; только бесплатные лимиты; Cloud Scout при исчерпании; handoff локально |
| Автономность | A4-Bounded: полная внутри разрешённых зон, hard deny снаружи |
| Права | Ядро без admin; elevated broker для admin-задач; WSL2/песочница |
| Prompt injection | Многослойная защита: trust labels, карантинный читатель, Policy Engine, egress, тесты |
| Приоритеты | Код → ПК → браузер → почта/Telegram → файлы/документы |
| Проекты | Новое ядро + модули; `ai-agent` → `work_crm`; всё обновляемое |
| Бюджет | $0 на облако; GPU 12–16 ГБ + M.2 SSD 1 ТБ через 1–2 месяца |
| Интерфейс | CLI + Web-UI; анимация речи; 3D-аватар; женский голос; Kivi |
| Аватар | 18 лет, 156 см, бирюзовые волосы/глаза, реалистичный аниме, без аксессуаров; VRoid/Blender |
| Показ аватара | Рабочий стол всегда; отдельное окно; второй монитор; скрытие по запросу |
| Одежда | 5 вариантов в `docs/PERSONA.md`; выбор за пользователем |
| Голос | Женский, мягкий, спокойный; сэмплы в `assets/voice-samples/` |
| Telegram | Бот |
| Работа | Карточка, комментарий, чек-лист, статус, акт, задача; всё кроме общения с клиентом |
| Shell | Полноэкранная замена Explorer; Explorer — fallback |
| Видео | Бесплатные облачные сервисы; локальный fallback |
