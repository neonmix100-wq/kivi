## 1. Уже решено

| Тема | Решение |
|---|---|
| Облако | Автоматически, локальные модели в приоритете; только бесплатные лимиты; при исчерпании — handoff локально |
| Автономность | A4-Bounded: полная внутри разрешённых зон, hard deny снаружи |
| Права | Ядро без admin; elevated broker для admin-задач; WSL2/песочница |
| Приоритеты | Код → ПК → браузер → почта/Telegram → файлы/документы |
| Проекты | Новое ядро + модули; `ai-agent` оставить; всё обновляемое |
| Бюджет | $0 на облако; GPU 12 ГБ + SSD 1 ТБ через 1–2 месяца |
| Интерфейс | CLI + Web-UI; анимация речи; 3D-аватар; женский голос; Kivi |
| Видео | Через бесплатные облачные сервисы; локально — fallback |
| Долгосрочно | Kivi Shell (псевдо-ОС) поверх Windows; Linux позже |

## 2. Аватар Kivi

Нужно уточнить, чтобы начать концепт и модель:

1. **Стиль:** реалистичный аниме, полуреализм, чиби, стилизованный 3D?
2. **Референсы:** есть ли персонаж/картинка/готовая VRM? Пришлите файлы или ссылки.
3. **Внешность:** возраст, рост, телосложение, цвет волос/глаз, причёска.
4. **Одежда:** повседневная, форма, фантазийная; сезонность; аксессуары (очки, наушники).
5. **Характер мимики:** сдержанная или эмоциональная; улыбка, брови, жесты.
6. **Где показывать:** рабочий стол (оверлей), отдельное окно, full-screen shell, второй монитор?
7. **Размер:** на весь экран, поясной портрет, маленький компаньон в углу?
8. **Изготовление:** делаем в VRoid/Blender сами или заказываем модель? Бюджет?
9. **Озвучка:** женский голос — мягкий/энергичный/спокойный? Есть примеры?

**Рекомендация:** начать с 2D-заглушки в M1, параллельно сделать концепт-арт; 3D-VRM — M5.

## 3. Protected Zones (запретные места)

Пришлите стартовый список. Пример:

- `C:\Windows`, `C:\Program Files`, `C:\Program Files (x86)`, `C:\ProgramData\Microsoft`;
- `D:\Secrets`, `D:\Finance`, `D:\Work\Personal`;
- профили браузеров, `%APPDATA%\...`, хранилища паролей (`*.kdbx`), `.ssh`, `.gnupg`;
- рабочие CRM-данные: читать можно, отправлять в облако — нет?

Вопросы:

1. Какие папки **нельзя даже читать**?
2. Какие можно читать, но **нельзя изменять**?
3. Какие можно читать, но **нельзя отправлять в облако**?
4. Нужен ли отдельный Windows-пользователь `Kivi` для жёсткой изоляции?

## 4. Облако и бесплатные аккаунты

1. Какие сервисы уже есть: Google AI Studio, OpenRouter, Groq, Mistral, Hugging Face, Cloudflare?
2. Готовы ли регистрироваться в бесплатных? Телефон/почта для верификации?
3. Согласны ли, что бесплатные тарифы могут использовать данные для обучения?
4. Какие данные **никогда** не отправлять (файлы, скриншоты, переписка, CRM)?
5. Нужен ли ручной список разрешённых провайдеров?

**Рекомендация:** `cloud: auto_free`, но каждый новый провайдер — после подтверждения; denylist — жёсткий.

## 5. Права администратора

Подтверждаете схему?

- ядро Kivi — обычные права;
- admin-операции — через отдельный elevated broker с UAC;
- каждая операция — с подтверждением и аудитом.

Или хотите, чтобы Kivi всегда работала от администратора? (Не рекомендую.)

## 6. Почта и Telegram

1. Почтовый провайдер: Gmail, Outlook, Яндекс, корпоративный? IMAP/SMTP или OAuth?
2. Нужно ли читать всю почту или только выбранные папки/метки?
3. Отправлять письма автономно или только черновики?
4. Telegram: **бот** (безопаснее, официальный API) или личный аккаунт (риск бана)?
5. Какие чаты/каналы разрешены? Кому можно отвечать автоматически?
6. Нужны ли уведомления и голосовое чтение?

## 7. Модуль работы (CRM)

1. Какой CRM/сервис: AltCRM `gs-leads.ru`? Какие ещё?
2. Какие шаги заказа автоматизировать первыми:
   - чтение заказа и звонков;
   - факты и черновик;
   - заполнение карточки;
   - акт;
   - задача;
   - сообщение клиенту;
   - звонок?
3. Что Kivi может делать **без человека**?
4. Что только готовить, а подтверждает человек?
5. Есть ли лимиты по скидкам/суммам/возвратам?
6. Какие метрики успеха: время на заказ, доля без вмешательства, ошибки?
7. Есть ли юридические ограничения на запись звонков и автоматические сообщения?

## 8. Kivi Shell (псевдо-ОС)

1. Полноэкранная оболочка вместо Explorer, оверлей поверх Windows или отдельное окно?
2. Нужны ли лаунчер приложений, поиск, файловый менеджер, виджеты?
3. Автозапуск при входе?
4. Заменять ли Explorer полностью или оставить оба режима?
5. Нужен ли второй монитор/мультимонитор?
6. Linux: нужен ли dual-boot/VM сейчас или позже?

**Рекомендация:** оверлей + отдельное окно; Explorer не трогаем; Linux — позже через абстракцию.
