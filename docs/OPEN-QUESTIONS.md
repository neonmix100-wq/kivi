# Открытые вопросы

Ответить можно коротко, например: `1B, 2A2, 3A, 4B, 5A…`
Для каждого вопроса указан **рекомендованный вариант** — если ответа нет, берём его.

---

## Блок A. Критические (влияют на архитектуру)

### 1. Облако и приватность

Разрешено ли отправлять данные в облачные API?

- **A. Только локально.** Никаких внешних вызовов. Максимальная приватность, но 8 ГБ VRAM — жёсткий потолок.
- **B. Гибрид по запросу (рекомендую).** Локально по умолчанию; облако — только после подтверждения на конкретную задачу.
- **C. Гибрид автоматически.** Gateway сам выбирает облако, если локально не влезает или качество ниже. Нужен бюджет и доверие.
- **D. Облако по умолчанию.** Локально — только мелочи.

Что нельзя отправлять никогда (папки, типы файлов, скриншоты, переписка)?

**Рекомендация: B**, `cloud: ask`, запрет на пароли/финансы/личные документы.

---

### 2. Уровень автономии

- **A0.** Только читает и отвечает.
- **A1.** Предлагает команды, выполняет только после явного «да».
- **A2 (рекомендую).** Безопасное делает сам; удаление, запись вне workspace, admin, сеть — с подтверждением.
- **A3.** Автономно в доверенных папках/сценариях; остальное — с подтверждением.
- **A4.** Полная автономия. Не рекомендую для старта.

Нужен ли режим «не беспокоить» (никаких подтверждений, только отчёт)? Для каких задач?

**Рекомендация: A2 + точечный A3** для `D:\AI-assistent\workspace` и повторяющихся безопасных сценариев.

---

### 3. Права и песочница

- Есть ли у вас права администратора на этом ПК? Готовы ли вы давать их ассистенту?
- Можно ли установить **WSL2** и/или **Docker Desktop**? (Сейчас WSL2 не установлен, Docker нет.)
- Использовать **Windows Sandbox** для недоверенных программ?

**Рекомендация:** ядро — без admin; для генерации кода — WSL2-дистрибутив `jarvis-sandbox`; admin-операции — через отдельный подтверждаемый помощник.

---

### 4. Запретные зоны

Какие пути/данные ассистент **не должен** читать, индексировать или отправлять?

Примеры: `D:\Secrets`, пароли браузера, бухгалтерия, личные фото, рабочие CRM-данные.

**Рекомендация:** denylist по умолчанию + шифрование секретов через DPAPI.

---

### 5. Бюджет

- Сколько в месяц готовы тратить на облачные API? (0 / до $10 / до $50 / больше)
- Планируете ли апгрейд GPU (16–24 ГБ) или внешний SSD?
- Есть ли ограничения по электроэнергии/шуму (ПК 24/7)?

**Рекомендация:** $0–10/мес на старте; внешний SSD 1 ТБ для моделей и видео.

---

### 6. Что делаем с существующими проектами

- `D:\ai-agent` — оставить как отдельное приложение и брать модули?
- `D:\workspace` — только идеи, код переписать?
- `D:\stable-diffusion-webui` — использовать для картинок?
- `D:\AI-base` — импортировать в память (read-only)?

**Рекомендация:** новое ядро в `D:\AI-assistent`; `ai-agent` не трогаем; VRAM-идеи переносим; SD WebUI используем; `AI-base` индексируем.
