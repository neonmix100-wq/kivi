# Медиа (M7): бесплатная генерация картинок через Pollinations

Первый срез M7 Cloud Media: инструмент `media.image` генерирует картинку через
публичный бесплатный сервис [Pollinations](https://pollinations.ai/) **без
API-ключа**, проверяет ответ и сохраняет файл в `data/media`. Локальный SDXL,
ComfyUI, очередь job'ов и видео в этот срез не входят.

Главный принцип тот же, что у `http.get` и `browser.read`: сгенерированная
картинка — это **данные из интернета**, а не команда. Результат помечается
`untrusted:web`; текст, который гипотетически может быть в метаданных или
OCR, не имеет права инструктировать планировщик.

Модули:

- `src/kivi/tools/media.py` — `MediaGenerateArgs`, `MediaImageTool`, сборка URL,
  проверка magic bytes и политика промптов;
- `tests/unit/test_media.py` — тесты без сети на `httpx.MockTransport`;
- этот документ.

## 1. Что реализовано, а что нет

| Возможность | Статус |

| `width`/`height` 256..1024, модели `flux`/`turbo`, `seed` | ✅ реализовано |
| Denylist NSFW/sexual/minor и запрет control-символов | ✅ реализовано |
| Проверка статуса, content-type, magic bytes, лимит 10 МБ | ✅ реализовано |
| Сохранение в `data/media/<uuid>.<ext>` через zone check | ✅ реализовано |

| Локальный SDXL/ComfyUI | ⬜ не подключён |
| Видео-провайдеры | ⬜ не подключены |

Инструмент намеренно не добавлен в `build_registry()` и не имеет
CLI-команды: это следующий интеграционный шаг, а не часть текущего среза.
`kivi tools list` его пока не показывает.

## 2. Архитектура

```text
пользователь / planner (trusted:user)
        │  media.image(prompt, width, height, model, seed, negative_prompt)
        ▼
ToolExecutor  (capability media.generate, риск R1, аудит каждого вызова)
        ▼
MediaImageTool
  ├─ политика промпта (control chars, denylist)
  ├─ build_image_url  ── фиксированный хост image.pollinations.ai
  ├─ httpx.Client(timeout=120, follow_redirects=False)
  ├─ проверка 200 / image/* / magic bytes / <= 10 МБ
  └─ атомарная запись в <workspace>/data/media/<uuid>.<ext>
        ▼
ToolResult(ok, artifacts=[...], trust="untrusted:web")
```

- Инструмент не видит БД и не вызывает другие инструменты; всё идёт через
  `ToolExecutor`, поэтому permission-проверка и аудит обязательны.
- Никакого ключа, токена или аккаунта: запрос — обычный публичный GET.
- Локальные файлы не загружаются: у аргументов нет пути, URL или файла,
  `extra="forbid"` отвергает любые лишние поля.
- Прокси/редиректы не используются. `follow_redirects=False`, ответ 3xx
  считается ошибкой.

## 3. Аргументы

`MediaGenerateArgs` — Pydantic-модель с `extra="forbid"`.

| Поле | Тип | По умолчанию | Ограничения |
|---|---|---|---|
| `prompt` | `str` | — | 1..500 символов, обрезается по краям |
| `width` | `int` | `1024` | 256..1024 |
| `height` | `int` | `1024` | 256..1024 |
| `model` | `Literal["flux", "turbo"]` | `"flux"` | только два значения |
| `seed` | `int \| None` | `None` | 0..2 147 483 647; без `seed` — случайный |
| `negative_prompt` | `str \| None` | `None` | до 500 символов |

Пример:

```json
{
  "prompt": "a red fox in snow, soft morning light",
  "width": 1024,
  "height": 768,
  "model": "flux",
  "seed": 42,
  "negative_prompt": "blurry, low quality, text"
}
```

Риск — **R1**: запись нового файла внутри workspace. В режиме `A4-Bounded`
это автоматическое действие; при более строгой автономии (`A2` и ниже)
сработает общая таблица рисков, как для любого R1-инструмента.

## 4. URL и параметры

Хост зашит в код. Единственный шаблон:

```text
https://image.pollinations.ai/prompt/<percent-encoded prompt>?width=...&height=...&model=...&nologo=true[&seed=...][&negative_prompt=...]
```

- `prompt` кодируется через `urllib.parse.quote(..., safe="")`: `/`, `?`, `#`,
  `%`, пробелы и не-ASCII не могут изменить путь или хост. Строка
  `https://evil.example/x` останется текстом внутри пути.
- `width`, `height`, `model`, `nologo=true` передаются всегда.
- `seed` добавляется только если он задан; так повторный вызов без seed
  получает новую картинку, а с seed — воспроизводимую (в пределах
  возможностей провайдера).
- `negative_prompt` передаётся как query-параметр best-effort: бесплатный
  endpoint может его учитывать не так строго, как платные API.
- `build_image_url()` дополнительно проверяет `urlsplit(url).hostname` и
  отказывается собирать что-либо, кроме `image.pollinations.ai`.

`nologo=true` просит провайдера не добавлять свой логотип. Провайдер может
менять поведение параметров без предупреждения — это бесплатный публичный
сервис.

## 5. Проверка ответа

До записи файла инструмент проверяет:

1. **Статус ровно 200.** 3xx — ошибка «redirects are not followed», 4xx/5xx —
   `HTTP <код>`. Автоматических retry нет.
2. **Content-Type.** Должен начинаться с `image/` и быть одним из
   `image/png`, `image/jpeg`, `image/webp` (алиасы `image/jpg` и
   `image/pjpeg` приводятся к `image/jpeg`). `image/gif`, `image/svg+xml` и
   любой не-image тип отвергаются.
3. **Magic bytes.** PNG — `89 50 4E 47 0D 0A 1A 0A`, JPEG — `FF D8 FF`,
   WebP — `RIFF....WEBP`. Заголовку Content-Type не доверяем: расширение
   файла берётся из magic bytes, а не из заголовка. Это защищает от подмены
   «картинки» HTML/скриптом.
4. **Размер.** Не больше **10 МБ** (`MAX_IMAGE_BYTES`). Проверяются и
   заявленный `Content-Length`, и фактически прочитанные байты; чтение идёт
   потоком, чтобы не принять гигантский ответ целиком.
5. **Тело не пустое** и реально начинается с известной сигнатуры.

Только после этого создаётся файл. Ошибка проверки — это `ToolError`, который
executor возвращает как `ToolResult(ok=False)`, а не падение процесса.

## 6. Политика промптов

Два независимых барьера, оба срабатывают **до** сети.

### 6.1. Control-символы и bidi

Промпт и `negative_prompt` не должны содержать символы категорий Unicode
`Cc`, `Cf`, `Cs`, `Co`, `Cn`: C0/C1-контролы, NUL, bidi-override, zero-width,
BOM и подобные. Это отсекает попытки спрятать текст, разорвать строку или
подсунуть невидимые маркеры. Обычный перевод строки и табуляция тоже
запрещены: для описания картинки они не нужны.

### 6.2. Denylist

`DEFAULT_PROMPT_DENYLIST` — явные термины NSFW/sexual/minor: `nsfw`, `porn*`,
`nude`, `naked`, `sexual`, `sex`, `hentai`, `erotic*`, `genitals`, `bdsm`,
`rape`, `incest`, `bestiality`, `child*`, `kid*`, `minor*`, `underage`, `teen*`,
`loli`, `shota`, `cp` и ряд других. Сравнение идёт по словам: регистр,
пунктуация и дефисы не помогают обойти проверку, а `childhood` не совпадает
с `child`.

`MediaImageTool(blocked_terms=(...))` **добавляет** термины к дефолтному
списку. Убрать дефолтные термины нельзя: политика не ослабляется
конструктором. Denylist применяется к положительному промпту; к
`negative_prompt` — только проверка control-символов, потому что `nsfw` в
негативном промпте — нормальная практика.

Это грубая эвристика, а не классификатор. Список англоязычный и заведомо не
исчерпывающий: он не гарантирует, что провайдер не сгенерирует нежелательное
изображение, и не заменяет правила сервиса. Ответственность за промпт и
использование результата остаётся на пользователе. Обход denylist не является
поддерживаемым сценарием.

## 7. Выходные файлы

```text
<workspace>/data/media/<32 hex uuid>.<png|jpg|webp>
```

- Путь не задаётся моделью или пользователем: имя генерирует инструмент.
- Перед записью путь проходит `ProtectedZones.check(path, "write")`; выход за
  workspace, symlink/junction и защищённые зоны запрещены.
- Запись атомарная: временный файл в том же каталоге, затем `replace`.
  Перезаписи нет — UUID уникален.
- Картинка **не парсится** и не декодируется: PIL/Pillow не нужен, размеры
  `width`/`height` в результате — запрошенные, а не фактические. Если нужен
  фактический размер, это отдельный шаг с явным декодером.
- В `ToolResult.meta` возвращаются `path`, `url`, `bytes`, `width`, `height`,
  `model`, `seed`, `content_type`, `detected_type`.
- `artifacts` содержит один путь. Дальше его можно отдать памяти/артефактам,
  но только как `untrusted:web`-файл.

## 8. Rate limits, SLA и ошибки

- Pollinations — **бесплатный публичный сервис**. API-ключ не нужен, но и
  стабильной квоты/SLA нет: условия, лимиты и доступность могут меняться без
  предупреждения.
- Лимиты обычно считаются по IP и могут проявляться как `429`, `5xx`,
  очередь или таймаут. Точных гарантированных цифр в коде нет, и Kivi их не
  обещает.
- Инструмент делает **один** запрос на вызов, не ретраит автоматически и не
  обходит лимиты. При `429`/`5xx` возвращается ошибка; повтор — решение
  вызывающей стороны с паузой.
- Таймаут — **120 секунд**. Медленная генерация — нормальный сценарий для
  free tier; это не повод запускать параллельно десяток запросов.
- Ошибки: сеть, редирект, не-200, не-image, битые magic bytes, превышение
  10 МБ, заблокированный промпт. Все они приходят как `ok=False` с текстом
  причины; частичный файл не остаётся.
- Fallback на локальный SDXL или другого провайдера **не реализован**.

## 9. Приватность и ToS

- Промпт уходит на сторонний сервис по HTTPS. Не вставляйте в промпт секреты,
  токены, пароли, персональные данные, адреса и содержимое приватных файлов.
- Kivi не загружает локальные файлы и не передаёт API-ключ: отправляется
  только текст промпта и параметры генерации.
- Провайдер может логировать запросы и хранить/публиковать изображения по
  своим правилам. Политика Pollinations и лицензии моделей (`flux`, `turbo`)
  применяются напрямую; перед коммерческим использованием результата
  проверьте их.
- Запрещены генерация NSFW/sexual-контента с участием несовершеннолетних,
  обход фильтров, автоматическая регистрация, обход CAPTCHA и любые действия
  против ToS провайдера. Denylist — лишь первый барьер.
- Сгенерированное изображение может быть неточным, оскорбительным или
  нарушающим чужие права. Это не доверенный контент и не факт.

## 10. Локальный SDXL/ComfyUI — не подключён

В проекте есть опциональные зависимости `image` (`diffusers`, `transformers`,
`accelerate`, `safetensors`) и скачанный чекпойнт SDXL base 1.0, но **раннера
нет**: `media.image` всегда ходит в Pollinations. Локальный путь потребует:

- отдельного провайдера/инструмента за тем же интерфейсом (например,
  `media.local` или стратегия внутри `media.generate`);
- загрузки SDXL только через `ModelGateway` и с учётом VRAM (16 ГБ хватает
  на SDXL 1024×1024, но не вместе с 8B Q4);
- ComfyUI/SD WebUI как внешнего процесса или собственного diffusers-пайплайна;
- тех же проверок файла, зон и trust-метки.

До этого локальная генерация не является fallback'ом и не упоминается как
доступная возможность.

## 11. Следующие видео-провайдеры — не подключены

Следующий шаг M7 — видео. Рассматриваются бесплатные кредиты/watermark и
официальные API (например, Wan/LTX через HF Spaces, Runway/Pika/Luma/Kling —
по факту доступности и ToS). Общие требования к будущему срезу:

- асинхронный цикл submit → poll → download → artifact, а не один длинный
  HTTP-запрос;
- лимит размера, длительности и разрешения; watermark и кредиты учитываются;
- тот же фиксированный-host/denylist/zone-подход;
- запрет авто-регистрации, обхода CAPTCHA, мультиаккаунтинга и нарушения ToS;
- fallback на локальный 480p/короткий клип, только если он реально
  реализован.

Сейчас ни одного видео-инструмента в реестре нет.

## 12. Интеграция и тесты

Текущий срез не трогает `src/kivi/tools/registry.py` и CLI. Чтобы включить
инструмент, в отдельном коммите нужно:

1. зарегистрировать `MediaImageTool()` в `build_registry()`;
2. добавить capability `media.generate` в выдачу grant'ов там, где это
   разрешено политикой;
3. добавить строку в таблицу `docs/TOOLS.md` и CLI-команду, если она нужна;
4. пересобрать `docs/_INDEX.md` и `docs/_CODE-MAP.md`
   (`python scripts/build_knowledge_index.py`).

Проверки среза:

```powershell
.venv\Scripts\python.exe -m pytest -q tests\unit\test_media.py
.venv\Scripts\python.exe -m ruff check src\kivi\tools\media.py tests\unit\test_media.py
```

Тесты не ходят в сеть: клиент собирается на `httpx.MockTransport`. Покрыты
успешный PNG, JPEG/WebP и расширение по magic bytes, кодирование prompt и
query-параметры, dry-run без сети, HTTP-ошибка, редирект, не-image,
неподдерживаемый image-тип, битые magic bytes, превышение 10 МБ, слишком
длинный промпт, заблокированный промпт, control-символы, путь под
`data/media`, R1-аудит и отказ без capability `media.generate`.
