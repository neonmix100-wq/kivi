## Big Fat Blue Fish (VRM)

- Файл: `assets/avatar/kivi.vrm` (локально, в git не входит).
- Автор: **Mzkagami** (X: `@mzkagami`, `mzkagami@zohomail.cn`).

- Формат: VRM 0.x (glTF 2.0, расширение `VRM`), около 35 МБ.

### Условия автора (из ReadMe.txt)

Разрешено:

- менять модель и цвета;
- менять одежду при сохранении характера персонажа;
- делать видео/изображения и публиковать в соцсетях.

Запрещено:

- **коммерческое использование**;
- **распространение**, включая изменённые версии;
- извлечение ассетов для других моделей;
- использование как личный аватар для стримов/лайвов;
- политическая/религиозная пропаганда, насилие, личные атаки, порнография;
- скрытие/удаление/изменение авторства.

Kivi использует модель **только локально, в личных некоммерческих целях**.
Файл исключён из git через `.gitignore`; не публиковать и не передавать его.
