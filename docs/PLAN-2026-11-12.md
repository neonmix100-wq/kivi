Факты и baseline: [BASELINE](BASELINE.md). Статус: [STATUS](STATUS.md).

## 2. Что изменилось относительно прошлого плана

| Было (план) | Стало (факт) | Следствие |
|---|---|---|
| RTX 3060 Ti 8 ГБ | **RTX 4060 Ti 16 ГБ** | +8 ГБ VRAM; 8B Q5, 14B Q4, SDXL и Whisper стали реалистичны |
| 1,8 ГБ свободной VRAM | ~14,5 ГБ | больше не нужно закрывать браузер ради 4B |
| 8B Q4 упиралась в 8 ГБ | 8B Q4 — 9,7 ГБ, Q5 — 10,6 ГБ | 8B Q5 можно сделать основным чатом |
| deepseek 12 tok/s | deepseek 46 tok/s на 16k | 16 ГБ сняли bottleneck |
| SDXL «потом» | SDXL ~6,8 ГБ | M7 можно делать локально уже сейчас |
| 14B «с offload» | 14B Q4 ~9–10 ГБ | реальный кандидат, но нужен замер |
| D: 126 ГБ | D: 120 ГБ | 14B + SDXL + whisper помещаются, датасеты — нет |

Главное: **16 ГБ снимают VRAM-ограничение, но не ограничение по CPU (4 ядра)
и не проблему нехватки ассетов** (VRM, wake ONNX, реальный AltCRM).

## 3. Новый baseline (12.11.2026)

| Модель | Контекст | Загрузка | Tokens/s | Peak VRAM |
|---|---:|---:|---:|---:|
| `qwen3.5:4b` | 8192 | 5.35 с | 54.3 | 7 787 МБ |
| `Qwen3-8B Q4_K_M` | 8192 | 5.72 с | 38.2 | 9 731 МБ |
| `Qwen3-8B Q5_K_M` | 8192 | 6.09 с | 27.9 | 10 565 МБ |
| `qwen2.5-coder:7b` | 16384 | 4.72 с | 43.4 | 9 043 МБ |
| `deepseek-coder:6.7b` | 16384 | 4.50 с | 46.2 | 15 541 МБ |

Выводы:

- **8B Q5 — основной чат**, 8B Q4 — быстрый вариант, 4B — router/fastpath;
- **7B coder @16k — основной Coder**; deepseek @16k только впритык;
- 4B @8k занимает 7,8 ГБ — для router лучше 4096, чтобы не тратить VRAM;
- первый холодный запуск может быть в 5–10 раз дольше; в метриках отделять
  cold load от warm.

## 4. Новая модель маршрутизации

| Задача | Модель | Контекст | Ожидаемый VRAM |
|---|---|---:|---:|
| Router / fastpath | `qwen3.5:4b` | 8192 | ~7,8 ГБ |
| Чат по умолчанию | `Qwen3-8B Q4_K_M` | 8192 | ~9,7 ГБ |
| Качественный чат | `Qwen3-8B Q5_K_M` | 8192 | ~10,6 ГБ |
| Coder | `qwen2.5-coder:7b` | 16384 | ~9 ГБ |
| Coder Pro (после установки) | `qwen2.5-coder:14b` Q4 | 8192 | ~9–10 ГБ |
| Vision | `qwen2.5vl:3b` | 4096 | ~3,6 ГБ |
| ASR | `faster-whisper-large-v3-turbo` | — | ~2 ГБ |
| Embeddings | `bge-m3` | CPU | 0 |
| Image | SDXL | 1024 | ~6,8 ГБ |

Правило: **одна тяжёлая модель**; 8B Q5 + Whisper + 3D-аватар (~12,9 ГБ)
помещаются, 8B Q5 + SDXL (~17,4 ГБ) — нет.

## 5. Приоритеты

### P0 — уже сделано (12.11.2026)

- перепроверены CPU/RAM/GPU/диски/ОС;
- baseline на 16 ГБ снят;
- `vram_total_mb` = 16384, `safety_margin_mb` = 512;
- `config/models.yaml` обновлён под реальные замеры;
- deepseek @16k помечен как «впритык», для него 8192.

### P1 — 14B и модели (1–2 дня)

1. Установить `qwen2.5-coder:14b` (Q4) или `Qwen3-14B Q4_K_M`.
2. Замерить load/tokens/s/VRAM при 8192 и 16384.
3. Если 16384 не влезает — оставить 8192; если влезает — добавить в registry.
4. Скачать `faster-whisper-large-v3-turbo` и SDXL-чекпойнт; замерить.
5. Проверить 8B Q5 + Whisper + 3D-аватар одновременно.

**Приёмка:** 14B работает ≥ 20 tok/s при 8192, не вызывает OOM; 8B+ASR+аватар
помещаются; SDXL генерирует 1024×1024 без выхода в shared memory.

### P2 — M7 Cloud Media (3–5 дней)

Теперь это самый разблокированный крупный этап.

1. Локальный SDXL через ComfyUI/SD WebUI: `image.generate`, 1024×1024, 20 steps.
2. Бесплатные облачные image/video-провайдеры через Cloud Broker с квотами.
3. 10 сценариев: аватар, иллюстрация, обложка, фото-ретушь, видео-клип.
4. Метрики: время, VRAM, стоимость (0), доля успешных.

**Приёмка:** 10 сценариев, ни одного платного вызова без разрешения,
SDXL не запускается одновременно с 8B.

### P3 — закрытие M5/M6 внешними ресурсами (параллельно)

M5 (~65%):

- `assets/wake/kivi.onnx` — кастомная wake-модель;
- `assets/avatar/kivi.vrm` — VRM 1.0;
- микрофон и замеры false wake/WER;
- 8B Q5 + Whisper + аватар теперь помещаются — можно тестировать живьём.

M6 (~70%):

- доступ к реальному AltCRM (CDP, залогиненная карточка);
- 10 реальных заказов в режиме «Kivi готовит»;
- графическая панель и паритет с extension;
- без этого этап остаётся 🟡.

### P4 — M8 Kivi Shell (после M7)

- Explorer-замена, панели, fail-safe;
- 16 ГБ не влияет напрямую, но аватар/браузер теперь не конкурируют за VRAM.

### P5 — backlog

- OCR/PDF-читатели;
- автоподключение approvals к PermissionEngine;
- живой облачный ключ;
- 1 ТБ SSD, если датасеты/видео перестанут помещаться.

## 7. Метрики и приёмка

- 14B: warm load < 8 с, ≥ 20 tok/s, без OOM.
- 8B Q5 + Whisper + 3D-аватар: ≤ 13,5 ГБ peak, без shared memory.
- SDXL 1024×1024: ≤ 60 с на 20 steps, ≤ 7,5 ГБ.
- 10 image/video-сценариев M7.
- 10 реальных заказов M6 — только при доступе к AltCRM.
- false wake < 1/час, WER, voice command < 3 с — после микрофона/моделей.
- `pytest -q` и `ruff check src tests` — зелёные на каждом шаге.
