                      Закройте все окна Chrome и запустите отдельный профиль:
                      & "C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="C:\chrome-agent"
                    
            2. 
                    
          2. 
                      Войдите в AltCRM в этом окне один раз. Пароль вводит человек —
                      Kivi его не видит и не хранит.
                    
            3. 
                    
          3. 
                      Откройте карточку заказа (например,
                      https://<crm>/devices/order/<id>) и оставьте
                      вкладку открытой.
                    
            4. 
                    
          4. Вернитесь сюда и нажмите «Проверить».
            5.
